# PPFS KPI & Network Monitoring Platform (CUP โรงพยาบาลโคกศรีสุพรรณ)

ระบบติดตามตัวชี้วัดงานส่งเสริมสุขภาพและป้องกันโรค (PP&P / PP Free Schedule: PPFS) 
และศูนย์ควบคุมเฝ้าระวังข้อมูลเครือข่าย รพ.สต. ทั้ง 10 แห่งในอำเภอโคกศรีสุพรรณ จังหวัดสกลนคร

---

## 🎯 จุดเด่นและขีดความสามารถของระบบ

1. **Smart Denominator Engine (คำนวณเป้าหมายจริงแม่นยำ)**
   - คำนวณกลุ่มเป้าหมาย (Denominator) จากฐานประชากรในเขตพื้นที่รับผิดชอบ (Type Area 1 & 3)
   - กรองเงื่อนไขเฉพาะของแต่ละตัวชี้วัดอัตโนมัติ: เพศ, ช่วงอายุ, และรอบความถี่ของบริการ
2. **10 PPFS Indicators Coverage (10 ตัวชี้วัดสำคัญ)**
   - HPV DNA Test (สตรี 30-59 ปี, อัตราจ่าย 400฿)
   - FIT Test คัดกรองมะเร็งลำไส้ใหญ่ (50-70 ปี, อัตราจ่าย 100฿)
   - คัดกรองเบาหวาน DM (35 ปีขึ้นไป, อัตราจ่าย 100฿)
   - คัดกรองความดันโลหิต HT (35 ปีขึ้นไป, อัตราจ่าย 50฿)
   - คัดกรองและประเมินผู้สูงอายุ 60+ (สายตา/ช่องปาก/หกล้ม, อัตราจ่าย 120฿)
   - คัดกรองพัฒนาการเด็ก DSPM (0-5 ปี, อัตราจ่าย 150฿)
   - เคลือบฟลูออไรด์ & ตรวจฟัน (เด็กเล็ก/ผู้สูงอายุ, อัตราจ่าย 100฿)
   - วัคซีนไข้หวัดใหญ่ (65 ปีขึ้นไป/กลุ่มเสี่ยง, อัตราจ่าย 150฿)
   - คัดกรองซึมเศร้า 2Q/9Q (15 ปีขึ้นไป, อัตราจ่าย 50฿)
   - ฝากครรภ์คุณภาพ ANC (หญิงตั้งครรภ์, อัตราจ่าย 400฿)
3. **CUP League Table & Multi-Level Filtering**
   - ตารางจัดอันดับผลงานเปรียบเทียบระหว่าง รพ.สต. ทั้ง 10 แห่งใน CUP
   - เลือกสลับมุมมองระหว่างภาพรวมทั้งอำเภอ หรือเจาะจงเฉพาะ รพ.สต. แต่ละแห่งได้อิสระ
4. **Target Patient Outreach & Call List (ดึงข้อมูลลงพื้นที่)**
   - บัญชีรายชื่อคนไข้ "ยังไม่ได้รับบริการ" (Unserved) และ "รับบริการแล้ว"
   - แสดง HN, เลขบัตร, ชื่อ-สกุล, อายุ, ที่อยู่, หมู่ที่, ตำบล, เบอร์โทรศัพท์ติดต่อ
   - **ปุ่มส่งออก Excel (.xlsx)** พร้อมจัดตารางสวยงาม ให้ อสม. และเจ้าหน้าที่สาธารณสุขนำไปเคาะประตูบ้าน
5. **Financial Estimation & Revenue Gap Analysis (ประมาณการรายรับ สปสช.)**
   - ประมาณการรายรับเต็มศักยภาพ (Target Revenue)
   - รายรับที่เบิกได้จริงตามผลงานสะสม (Actual Revenue)
   - รายรับที่ยังตกหล่น (Revenue Gap) พร้อมจัดลำดับตัวชี้วัดที่มีมูลค่าคุ้มค่าที่สุดในการเร่งรัด
6. **Pre-Audit Data Quality Engine (ตรวจเช็คเงื่อนไขก่อนส่งเคลม)**
   - ตรวจจับเคสที่ลงข้อมูลผิดเกณฑ์ (อายุผิด, เพศไม่ตรง, ตรวจซ้ำซ้อนในระยะเวลาที่ห้าม)
   - ป้องกันการถูกปฏิเสธการจ่าย (Denial Prevention) พร้อมประเมินมูลค่าเงินที่เสี่ยงถูกตัด
7. **Hybrid Network Architecture (เชื่อมโยงฐานข้อมูล รพ.สต.)**
   - รองรับการเชื่อมต่อตรงไปยัง GDCC Cloud Database ของ รพ.สต. 
   - และมีระบบ Fallback ไปยังฐานข้อมูลแม่ข่าย HOSxP Hub เพื่อให้ระบบทำงานได้ 100% ตลอดเวลา

## 🚀 การเริ่มต้นใช้งาน (Getting Started)

### เข้าใช้งานผ่าน Web Browser
- **Frontend URL:** [http://localhost:5180](http://localhost:5180)
- **Backend API URL:** [http://localhost:3600](http://localhost:3600)
- **เครื่องอื่นในวงแลน:** [http://10.10.20.224:5180](http://10.10.20.224:5180)

### คำสั่งเปิดระบบ (เมื่อต้องการเปิดรันใหม่)
```bash
cd d:\ppfs-kpi

# 1. รัน Backend API Server (Port 3600)
npm run server

# 2. รัน Frontend Web App (Port 5180)
npm run dev
```
